## Findings to put in the PR
- **Upstream latency is short by 1 + host/inner samples.** `ResamplingContainer::GetLatency()` returns the warm-up
  length only: 27/39/42 at 44.1/88.2/96 kHz, against a measured 28.92/41.84/45.0. `readSample()` centres each stage's
  output one input sample late (its fractional weight is `kernel(1 - frac)`). The fork reports the derived exact
  delay `warmup + 1 + host/inner` and rounds it for `getLatencySamples()`.
- **Hosts above 48 kHz alias on the down leg (upstream behaviour, unchanged).** The Lanczos kernel is not scaled to
  the lower Nyquist when going host -> 48 kHz. At 96 kHz host, a 30 kHz input comes out at 18 kHz at 0 dBc (full
  level). The up-leg image of a 20 kHz tone (at 28 kHz) is -46 dBc, and the passband is flat to -0.09 dB at 20 kHz.
  Guitar DI has little content above 24 kHz, but drive blocks running before the amp at 88.2/96 kHz can produce it.
  This is a candidate follow-up for P5-4 (#170, owner dsp-engineer): scale the kernel by min(1, out/in) for
  downsampling, or put a band-limit before the NAM slot. It is not done here because ADR-0002 D4 says "as upstream".
  Measured with a throwaway test, not committed.
- Ring buffers are sized in prepare(), so upstream's fixed 2 x 131072 floats per resampler are gone. The kernel
  tables (1.5 MB) are built once behind a thread-safe function-local static.

## Gotchas
- **Licence notice placement (decision, needs a reviewer's eye).** `tools/guard/check_repo.py` rejects the company
  name inside the iPlug 2 zlib-style notice ("third-party libraries" list) in a `.h` file. That notice says it "may
  not be removed or altered", and the guard is outside this slice's files. So the original notices are kept
  **verbatim** in `engine/src/nam/RtResampler.NOTICE`, an attribution file next to the source, like `THIRD_PARTY.md`
  (AGENTS.md rule 2). The header points to it and lists the changes. The alternative is a guard exemption for
  `engine/src/nam/RtResampler.h` (owner: release-devops), which would let the notice move back into the header.
- The in-app Credits text must carry the MIT notice for the binary (owner: ui-engineer, when NAM ships).
- Eigen comes from gitlab.com. A cold clone once failed with "GitLab is currently unable to handle this request
  due to load"; it worked on retry.
- MSVC `std::regex` has no `multiline` flag (used to hit this in the include-isolation test, fixed in #188).
