# OpenSourcePedal

An open-source guitar amp-and-effects processor for Windows: a **standalone app** (ASIO first, low latency) and a
**VST3 plugin**. Amps are hybrid: you can load neural captures in the [Neural Amp Modeler](https://github.com/sdatkinson/neural-amp-modeler)
`.nam` format, and classic-DSP amp models are built in. Pedals and effects are classic DSP. You can load your own cabinet impulse responses (IRs).

**Signal chain (per preset):** noise gate → compressor → overdrive/boost → amp (multi-channel) → cab (2 IRs + mic blend)
→ EQ (graphic + parametric) → modulation → delay (digital/analog/tape, tempo sync) → reverb (room/hall/plate/ambient shimmer)
→ output. Plus a tuner and global settings.

> **Status:** early development, built by a team of autonomous coding agents. See [`docs/ROADMAP.md`](docs/ROADMAP.md) and
> [`docs/state/ORCHESTRATOR.md`](docs/state/ORCHESTRATOR.md) for live progress.

## Building (Windows)

> The build system lands in Phase 3 ("walking skeleton"). The commands below are the target interface.

Requirements: Visual Studio 2022 (C++20, MSVC v143), CMake ≥ 3.25, Git LFS, Python 3.11+.

```powershell
git lfs install
git clone https://github.com/ArthurMateus/OpenSourcePedal
cd OpenSourcePedal
cmake --preset windows-msvc        # fetches JUCE and the ASIO SDK at configure time
cmake --build --preset release
ctest --preset release
```
